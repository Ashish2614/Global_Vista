# Global Vista

An animated, responsive React/Vite foundation for exploring the world's countries. Milestone 1 establishes the visual system, responsive landing layout, theme foundation, and reusable discovery sections.

## Run locally

```bash
npm install
npm run dev
```

Then open the local URL shown by Vite.

## Milestone 1 scope

- Responsive landing page with mobile navigation treatment
- Dark default theme and light theme toggle
- Hero/search experience foundation
- Popular country cards and discovery feature band
- Accessible labels, focusable controls, and reduced-motion support
